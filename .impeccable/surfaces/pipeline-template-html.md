Scope: the whole Skillshelf store (Home, Browse, My list, listing pages, install sheet). Visitor mode: Operate, with a Home that must state the benefit in 5 seconds.

Audience and job: everyday people and Claude Code users, equally. Success: (1) install the Skillshelf bar, (2) save picks to My list.

## Direction contract
THESIS: An app store everyone already knows how to use, for free software from GitHub. It refuses the cluttered catalog (nine ways in, one card shape, security badges) in favour of three tabs and one decision per screen.
OWN-WORLD: Apple App Store and Mac App Store grammar played straight: white and grouped-grey grounds, system type, large titles, rows with a grey Get pill, squircle icons using each project's real GitHub picture. Accent blue darkened for contrast. One Skillshelf mark: a small "Free alternative to X" tag where the project says so.
STORY: The visitor sees what Skillshelf is, finds something for a job or a paid tool they want to replace, reads four plain blocks, and lets Claude set it up (or saves it).
FIRST VIEWPORT: Home: large title "The app store for open source", one-line promise, a "What do you want to do?" search with idea chips; on desktop the Skillshelf bar card sits beside it, on phones after the free-alternatives shelf. Sidebar on desktop (Home, Browse, My list), tab bar on phones.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
