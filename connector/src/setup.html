Skillshelf

For Claude Code

Your skills, right above the message box

The Skillshelf bar stays attached to your chat. Switch skills on or off for the session, and add any skill after Skillshelf checks its code.

In Claude Code, run these two commands:

/plugin marketplace add {{MARKET}}
/plugin install skillshelf@skillshelf

Then start a new session. The bar shows up above your message box. Free, no account.

Switch skills on or off

One click per skill, for this session. Claude won't use a skill you switched off.

Add any skill, checked first

Paste a link or say what you need. Claude checks it with Skillshelf, tells you what it can reach, and asks before installing.

Ban phrases for good

Flag a word or phrase Claude keeps writing, and it won't write it again in any session.

Using Claude chats instead?

The bar is for Claude Code. In Claude's website, desktop app or phone app, add Skillshelf as a connector: then ask Claude for a skill and get checked picks.

Open Plugins in Claude ↗
  1. Open Plugins, click Add, then Add custom connector.
  2. Name it Skillshelf and paste the link.
  3. Start a new chat. Click + and switch Skillshelf on.

Switch it on before your first message. Switching it on in the middle of a chat doesn't load it.

Good to know

  • Add it only once. The bar brings Skillshelf's connector with it, so in Claude Code you don't need to add the connector as well. If Skillshelf shows up twice in your list, remove one.
  • Searching Claude's connector list won't find Skillshelf yet. Use the link above.
